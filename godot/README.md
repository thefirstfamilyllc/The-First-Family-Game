# The First Family: Build Your Empire — Godot foundation

This is the **new game source**, separate from the existing GitHub Pages 3D prototype at the repository root. The approved Home Screen is untouched.

## Intended platforms
Godot 4.x, Compatibility renderer, targeting web exports for laptop, Chromebook, and mobile browser testing. Godot's web support on iOS/Safari and school-managed devices must be tested; no compatibility guarantee is made.

## Run
Install free Godot 4.x on a development computer. Import the `godot/` directory as a project and run the main scene. This is source code, **not a hosted or tested game build**.

## Current scope
- One chosen playable character (Jay, Esined, or Jahdē)
- Third-person camera and keyboard/tap-to-move
- First neighborhood geometry and collision
- Action zones for laundry, pickups, rest, family time
- Initial cash/reputation/energy consequences

## Next production milestones
1. Replace procedural placeholder geometry with **licensed high-quality GLB environment and rigged character assets** matching the approved Home Screen's stylized realism.
2. Implement animation tree (idle/walk/interact), navigation mesh, furniture interactions, NPC daily schedules, camera orbit and touch joystick.
3. Implement age-based account entitlements, gameplay persistence, economy and story state.
4. Build and test a real web export on iPhone, Android, laptop and Chromebook.
5. Add driving, business management, family life, and city expansion incrementally.

Do not claim this code is polished graphics or a complete playable Sims-style game. It is the engine foundation only.
