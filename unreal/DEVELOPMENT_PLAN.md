# Production sequence

1. **Foundation:** UE5 project, third-person template, controller and camera, test map.
2. **Character production:** approved likeness reference sheets, model Jay/Esined/Jahdē, rig, animations, material variants.
3. **Character selection:** three real skeletal meshes on pedestals, orbit camera, choose/accept.
4. **Character customization:** separate 3D room, modular clothing/hair/appearance, persistent save game.
5. **First neighborhood:** roads, buildings, laundromat, residential pickup locations, traffic-safe boundaries.
6. **Laundry loop:** request -> pickup -> processing -> delivery -> payment, customer satisfaction.
7. **Business management:** finances, staff, supplies, upgrades, properties, cleaning services.
8. **Driving:** van physics, enter/exit, loading cargo, deliveries.
9. **Expansion:** additional businesses, family interactions, franchise progression.
10. **QA and packaging:** real hardware playtesting and distributable builds.

**Nonnegotiable:** no flat portrait substitutes or generic meshes presented as approved family likenesses.
